## 🖼️ Что делает это приложение

Image Converter создавался как небольшой вспомогательный инструмент для наведения порядка в референсах. Он помогает художникам поддерживать библиотеку изображений в чистоте и экономит время, которое обычно уходит на ручное переименование файлов.

Если вы собираете много референсов из Pinterest (в первую очередь), Artstation, Behance или Google Images, вы знаете эту боль: хаотичные имена файлов, странные расширения и ситуация, когда простое «переименовать в .jpg» делает файл недоступным для просмотра.

Данное приложение объединяет и автоматизирует два действия: **пакетное переименование** (по маске) и **реальную конвертацию**, чтобы файлы изображений корректно открывались и просматривались.
&nbsp;
&nbsp;

## 🎨 Функции

- Пакетное переименование неаккуратных имён файлов изображений в чистую маску вроде `ref_001.jpg`, `ref_002.jpg`…
- Конвертация в корректный формат (JPG/JPEG, PNG), чтобы файлы надёжно открывались.
- Автоматическая обработка дубликатов с добавлением `_copy`, `_copy2`…
- Очистка имён файлов (удаление недопустимых символов).
- Отображение прогресса, пропуск повреждённых файлов и простой рабочий процесс.
- Чистый и минималистичный интерфейс.

## ⚒ Установка

- Перейдите в раздел **Releases** и скачайте свежую версию `.exe`.
- Распакуйте архив в любое место (Рабочий стол, папка Tools, USB-накопитель).
- Запустите `Image Converter.exe`.
&nbsp;
&nbsp;

## 🏓 Как пользоваться

1. Выберите входную папку.
2. Укажите выходной формат.
3. Задайте маску имени файла (пример: `ref_###` → `ref_001`, `ref_002`…).
4. Нажмите **Start** и дождитесь завершения процесса.
